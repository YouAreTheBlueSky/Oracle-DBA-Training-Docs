# 協作模式：「第 X 章簡報我改好了」

這份文件定義一套固定的來回方式。你只要說一句話，後面的步驟由我執行。

## 你說的

> 第 4 章我改好了

（章號以你的教材為準；初階版與進階課程的編號各自從 01 起算。若同時改了多章，說「第 4、5 章」即可。）

## 我做的五步

1. **找檔案**：比對工作區最近修改的 `.pptx`，確認是哪一份（不用你給路徑）。
2. **比對**：以 `work/content/chNN.py` 重建一份基準，逐頁、逐形狀、逐段落與你的檔案比對。
3. **分類與處理**：

   | 差異類型 | 我的處理 |
   |---|---|
   | 純文字（句子、指令、通過條件） | 自動回寫模組，只改唯一出現的字串 |
   | 講者備忘 | 讀出你補的文字，存入該頁的 `_note_why`，與原備忘合併 |
   | 多／少一個段落、多／少一行 | 停手，回報「需人工對應」，並提出建議 |
   | 字級、顏色、位置、插圖 | 無法回寫，改走 `FROZEN.txt` 凍結該檔 |

4. **重建與驗證**：重建後再比對一次，確認「模組產生的檔案 = 你的檔案」；再檢查長度上限與是否觸發自動縮字。
5. **回報與存檔**：列出「你改了什麼／我改了模組哪一行／驗證結果」，commit 並 push。

## 回報長怎樣

```
你改了 3 處：
  第 04 頁程式碼 + SHOW PARAMETER SPFILE
  第 06 頁備忘 OFA 說明 368 字
  第 30 頁備忘 ASSM 說明 530 字
回寫模組：3 處成功，0 處略過
重新驗證：一致 [OK]｜體例檢查：都在上限內 [OK]
已 commit 25ac802 並 push
```

## 你需要避免的三件事

| 避免 | 原因 |
|---|---|
| 用 Shift+Enter 手動斷行 | 軟換行不是文字，重建後會消失（自然折行不受影響） |
| 改完不存檔就說改好了 | 我讀到的是舊檔 |
| 改版面（字級、顏色、位置）卻沒說 | 重建會還原；請先講，我幫你加進 `FROZEN.txt` |

PowerPoint 開著檔案時我仍可讀取，但重建寫入會失敗；若要重建，我會提醒你先關閉。

## 若哪天沒有內容模組

若你拿一份不是由模組產生、或沒有版控的簡報來改，流程降級為「與上次 commit 比對」：我仍能列出差異與備份，但無法回寫模組，改動只能留在 PPTX。這種情況我會先說明再動手。
